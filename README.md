### ✨ Key Features
- ✅ **Add Employee** - Store new employee records
- ✅ **Display All** - View all employees in table format
- ✅ **Search by ID** - Find employee instantly  
- ✅ **Update Data** - Modify employee info
- ✅ **Delete Record** - Remove employee from system
- ✅ **File Handling** - Data saved in `employee.dat` permanently

### 🛠️ Tech Stack Used
`C Programming` `Struct` `File I/O` `Data Structures` `CLI`
