# Employee Data Management System in C

A CLI based Employee Management System built using C Programming.

### Features
- ✅ Add New Employee
- ✅ Display All Employees 
- ✅ Search Employee by ID
- ✅ Update Employee Data
- ✅ Delete Employee
- ✅ Data saved in File using File Handling

### Tech Used
`C` `Struct` `File I/O`

### How to Run
```bash
gcc main.c -o employee
./employee
